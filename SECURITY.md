## Reporting a Vulnerability

### Vulnerabilities in This Repository

If you discover a security vulnerability in this repository (e.g., malicious links, compromised entries), please report it privately by creating a draft security issue or contacting the maintainers directly.

**Please do NOT create a public issue for security vulnerabilities.**

### Vulnerabilities in Listed Tools

If you discover a vulnerability in one of the tools or resources listed in this repository:

1. **Do not report it here** - We are not the maintainers of those tools
2. Contact the maintainers of that specific tool directly
3. Once reported to the tool's maintainers, you may create an issue here to discuss temporarily removing the link until the vulnerability is fixed

### What to Include

When reporting a security vulnerability, please include:

- Description of the vulnerability
- Steps to reproduce (if applicable)
- Potential impact
- Suggested fix (if you have one)
- Your contact information for follow-up

## Link Safety

We strive to ensure all links in this repository point to legitimate, safe resources. However, we cannot guarantee the security of external sites. 

### Our Commitment

- All links use HTTPS (not HTTP)
- We regularly check for broken or suspicious links
- We remove links to abandoned or compromised projects promptly
- We verify new submissions before merging

### If You Find a Suspicious Link

1. Create an issue using the "Report Issue" template
2. Select "Broken Link" or "Other" as the issue type
3. Provide details about why the link is suspicious
4. We will investigate within 48 hours

## Security Best Practices for Contributors

When contributing to this repository:

- ✅ Only submit tools from verified sources (official websites, GitHub, GitLab, etc.)
- ✅ Always use HTTPS URLs
- ✅ Verify the tool is actively maintained
- ✅ Test links before submitting
- ❌ Do not submit links to cracked/pirated software
- ❌ Do not submit links to malicious or questionable sites
- ❌ Do not submit affiliate links or spam
