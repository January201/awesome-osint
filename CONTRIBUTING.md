# Contribution Guidelines

Please ensure your pull request adheres to the following guidelines:

- Read [the awesome manifesto](https://github.com/sindresorhus/awesome/blob/master/awesome.md) and ensure your list complies.
- Search previous suggestions before making a new one, as yours may be a duplicate.
- Insert a new entry **alphabetically**. The prefix "The" (or any other language's equivelent of "the") is not considered in this sorting.
- Make an individual pull request for each suggestion.
- Titles should be [capitalized](http://grammar.yourdictionary.com/capitalization/rules-for-capitalization-in-titles.html).
- Use the following format: `[List Name](link)  - additional information.`
- New categories or improvements to the existing categorization are welcome.
- Check your spelling and grammar.
- Make sure your text editor is set to remove trailing whitespace.
- The pull request and commit should have a useful title.
- In your pull request, include a link in the textual description.
- If your submission is self-promotional or you are related to/work for the website, disclose that up front.
- Not everything belongs here. Before you make a PR, think to yourself "how would this help people doing OSINT?"

## 📋 Submission Process

### 1. Before Submitting
- **Search existing entries** to avoid duplicates
- **Verify the link works** and the tool is accessible
- **Ensure alphabetical ordering** within the target category
- **Read these guidelines completely**

### 2. Formatting Requirements

**Correct Format:**
```markdown
* [Tool Name](https://example.com) - Brief, informative description.
```

**Examples:**

✅ **Good Submissions:**
```markdown
* [Perplexity](https://www.perplexity.ai) - AI-powered search engine with source citations.
* [Shodan](https://www.shodan.io/) - Search engine for Internet-connected devices (IoT).
* [TinEye](https://tineye.com) - Reverse image search engine for finding image origins.
```

❌ **Bad Submissions:**
```markdown
* [perplexity](https://www.perplexity.ai) - cool ai tool  (incorrect capitalization, vague)
* [Perplexity](https://www.perplexity.ai)  (no description)
* [Perplexity AI Search Engine Tool](https://www.perplexity.ai) - Amazing tool for everything!!! (promotional)
* [PERPLEXITY](https://www.perplexity.ai) - AI search (all caps)
```

### 3. Required Information in Pull Requests

When submitting a PR, please include:
- **Tool name and URL**
- **Category** where it should be added
- **Brief description** (1-2 sentences explaining functionality)
- **Pricing model**: Free / Freemium / Paid / Open Source
- **API requirement**: Does it require an API key?
- **Maintenance status**: Is it actively maintained?
- **Disclosure**: Are you affiliated with this tool?

### 4. Quality Standards

**Tools must:**
- Be publicly accessible (no private/beta-only tools)
- Have clear OSINT utility (explain how it helps investigations)
- Be functional and not abandoned (last update within 2 years for software)
- Not violate privacy laws or terms of service of other platforms

**Descriptions should:**
- Be concise (1-2 sentences max)
- Explain the primary function
- Avoid marketing language or superlatives
- Be neutral and factual

### 5. Categories & Organization

- Add tools to the **most specific relevant category**
- If no appropriate category exists, suggest a new one with justification
- Maintain **alphabetical order** (ignoring "The" prefix)
- One tool per line, no sub-lists within categories

### 6. Self-Promotion Policy

If you are:
- The creator/developer of the tool
- Employed by the company
- Receiving compensation for promotion
- Otherwise affiliated

**You MUST disclose this in your PR.** Self-promotional submissions are evaluated more strictly and must provide exceptional value to the community.

## ⏱️ Response Time Expectations

- **Review timeframe**: 7-14 days for most submissions
- **Incomplete PRs**: May be closed or require additional information
- **High-volume periods**: Reviews may take longer during busy times
- **Be patient**: Maintainers are volunteers contributing their free time

## 🔍 Review Process

1. **Automated checks** run on all PRs (markdown linting, link checking, alphabetical order)
2. **Maintainer review** for content quality and relevance
3. **Community feedback** period (3-5 days for controversial additions)
4. **Merge or request changes**

## 🚫 Common Reasons for Rejection

- Duplicate entries
- Broken or inaccessible links
- Incorrect formatting or capitalization
- Vague or missing descriptions
- Tools without clear OSINT application
- Abandoned projects (no updates in 2+ years)
- Promotional/marketing language
- Failure to disclose affiliation
- Not alphabetically sorted
- Wrong category placement

## 💡 Tips for Successful Contributions

1. **Use the issue templates** if you're unsure about a submission
2. **Check recent merged PRs** to see current standards
3. **Keep descriptions factual** and avoid hype
4. **Test your links** before submitting
5. **Be responsive** to maintainer feedback
6. **One tool per PR** for easier review
7. **Follow the exact format** shown in examples

## ❓ Questions?

- Open a **discussion** for general questions
- Create an **issue** for problems with existing entries
- Check the **FAQ** section (coming soon) for common questions
